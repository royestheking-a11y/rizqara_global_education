Section 8: How It Works
Step-by-step process:

Step 1: Create Student Profile
Student adds academic information, target country, subject, budget, IELTS/MOI status.

Step 2: Get Scholarship Match
System shows suitable scholarships based on profile.

Step 3: Document Check
Student uploads passport, certificates, transcripts, CV, SOP, recommendation letter, etc.

Step 4: Application Processing
RizQara team checks and updates every step.

Step 5: Track Progress
Student dashboard shows application status.

Step 6: Final Submission / Visa Guidance
Student gets support until final stage.

21. Final Website Concept Summary
RizQara Global Education will be a smart scholarship platform where students can discover scholarships, filter by country/university/subject/funding/IELTS, view full details, apply for guidance, upload documents, track progress, receive notifications, chat with advisors, and use RizQara AI for personalized study abroad guidance.

Admin can manage everything from one powerful dashboard — scholarship, carousel, students, applications, documents, orders, notices, blogs, testimonials, AI knowledge, and website settings.

This system can become more than a website — it can become a complete digital scholarship consultancy platform for Bangladeshi students.
