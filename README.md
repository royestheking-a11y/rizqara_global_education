# Rizqara Global Education 🎓

Rizqara Global Education is Bangladesh's premier scholarship portal and study abroad consultancy. We empower students by providing a comprehensive platform to find fully-funded scholarships, manage their documents, and achieve their global education dreams.

---

## 🌟 Key Features

### 👨‍🎓 For Students
*   **Scholarship Discovery:** Search and filter hundreds of international scholarships.
*   **Professional Dashboard:** Manage profile settings and track scholarship applications.
*   **Secure Document Vault:** Upload and preview essential documents (Passport, SSC/HSC Certificates, CV, SOP, etc.) with 2MB file size limits and secure Cloudinary storage.
*   **Real-time Status:** Track application progress and verification status directly from the dashboard.

### 🛡️ For Administrators
*   **Lead Management:** Track and manage prospective student leads.
*   **Document Verification:** Review and verify student-uploaded documents.
*   **Content Management:** Update scholarships, blogs, and notice board entries in real-time.

### 💳 Integrated Payments
*   **Global & Local Options:** Secure payment gateway supporting Visa, Mastercard, Bkash, Nagad, and more.
*   **Transaction Tracking:** Professional payment flow with transaction ID verification.

---

## 🏗️ Tech Stack

*   **Frontend:** React (Vite), TailwindCSS, Lucide Icons, Framer Motion.
*   **Backend:** Node.js (Express), MongoDB (Mongoose).
*   **Cloud Storage:** Cloudinary (for secure document management).
*   **Authentication:** JWT (JSON Web Tokens) & Bcrypt hashing.

## 🚀 Getting Started

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/royestheking-a11y/rizqara_global_education.git
    ```

2.  **Install Dependencies:**
    *   Root (Frontend): `npm install`
    *   Server (Backend): `cd server && npm install`

3.  **Environment Setup:**
    Create a `.env` file in the `server` directory with:
    *   `MONGODB_URI`
    *   `JWT_SECRET`
    *   `CLOUDINARY_URL`

4.  **Run Locally:**
    ```bash
    npm run dev
    ```
